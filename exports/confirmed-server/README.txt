   CONFIRMED – النسخة الكاملة للنشر على السيرفر
═══════════════════════════════════════════════════════════════

📦 محتوى هذا المجلد:
  index.mjs      ← السيرفر الكامل (API + الواجهة معاً)
  public/        ← ملفات الواجهة (تُخدَّم تلقائياً)
  database.sql   ← جداول قاعدة البيانات (تُنشأ تلقائياً عند أول تشغيل)
  .env.example   ← قالب إعدادات البيئة
  setup.sh       ← سكريبت التهيئة التلقائية
  package.json   ← معلومات المشروع

═══════════════════════════════════════════════════════════════
   المتطلبات على السيرفر
═══════════════════════════════════════════════════════════════

  ✓ Node.js 20 أو أحدث   → https://nodejs.org
  ✓ PostgreSQL 14+        → قاعدة بيانات (محلية أو سحابية)
  ✓ PM2 (للتشغيل الدائم) → يُثبَّت تلقائياً بـ setup.sh

═══════════════════════════════════════════════════════════════
   طريقة التشغيل السريعة
═══════════════════════════════════════════════════════════════

الخطوة 1 — أنشئي قاعدة البيانات:
  psql -U postgres -c "CREATE DATABASE confirmed_db;"

الخطوة 2 — اعدّلي الإعدادات:
  cp .env.example .env
  nano .env
  (عدّلي DATABASE_URL و SESSION_SECRET و APP_URL)

الخطوة 3 — شغّلي السكريبت:
  bash setup.sh

═══════════════════════════════════════════════════════════════
   ماذا يحدث عند أول تشغيل؟
═══════════════════════════════════════════════════════════════

  1. السيرفر يبدأ ويستمع على البورت المحدد
  2. يتحقق من قاعدة البيانات — إذا لم تكن الجداول موجودة:
     ← ينشئها تلقائياً من ملف database.sql
  3. يُهيّئ الخدمات الافتراضية للصالونات
  4. يشغّل جدولة الإشعارات التلقائية
